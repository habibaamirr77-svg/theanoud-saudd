# موقع العنود سعود - بالـ Backend

هذا المشروع هو موقع شخصي للفنانة السعودية العنود سعود، مع دعم مشاركة المنشورات والرسائل لجميع المستخدمين عبر الخادم.

## المميزات الجديدة 🌟

### 📝 المنشورات
- إضافة صور وفيديوهات ونصوص
- **مشاركة البيانات لجميع المستخدمين** عبر الخادم
- نظام إعجاب متعدد
- حذف المنشورات

### 💬 رسائل المعجبين
- إرسال رسائل للعنود سعود
- **مشاركة الرسائل لجميع المستخدمين** عبر الخادم
- نظام إعجاب
- عرض جميع الرسائل بشكل جماعي

## طريقة التشغيل 🚀

### 1. تثبيت المتطلبات
```bash
npm install
```

### 2. تشغيل الخادم
```bash
npm start
```

### 3. فتح الموقع
افتح المتصفح وانتقل إلى:
```
http://localhost:3000
```

## الملفات الجديدة 📁

| الملف | الوصف |
|-------|-------|
| `server.js` | خادم Node.js مع قاعدة بيانات SQLite |
| `firebase.js` | ملف إعدادات Firebase (اختياري) |
| `package.json` | ملف تعريف المشروع |
| `website.db` | قاعدة بيانات SQLite (تُنشأ تلقائياً) |

## API Endpoints 📡

### المنشورات
- `GET /api/posts` - جلب جميع المنشورات
- `POST /api/posts` - إضافة منشور جديد
- `DELETE /api/posts/:id` - حذف منشور
- `POST /api/posts/:id/like` - إعجاب/إلغاء إعجاب

### الرسائل
- `GET /api/messages` - جلب جميع الرسائل
- `POST /api/messages` - إضافة رسالة جديدة
- `DELETE /api/messages/:id` - حذف رسالة
- `POST /api/messages/:id/like` - إعجاب/إلغاء إعجاب

## قاعدة البيانات 💾

يستخدم المشروع قاعدة بيانات SQLite لتخزين:
- المنشورات (نوع، محتوى، تاريخ، إعجابات)
- الرسائل (اسم، نص، تاريخ، إعجابات)
- سجل الإعجابات (لمنع التكرار)

## نشر على الإنترنت 🌐

### باستخدام Render.com (مجاني):
1. رفع المشروع لـ GitHub
2. ربط حساب Render بـ GitHub
3. إنشاء Web Service جديد
4. تحديد الأمر: `node server.js`
5. النطاق سيكون متاحاً مجاناً

### باستخدام Railway:
1. رفع المشروع لـ GitHub
2. ربط Railway بـ GitHub
3. إضافة SQLite كـ plugin
4. نشر الخدمة

## ملاحظات ⚠️

- البيانات المحفوظة في `website.db` تبقى على الخادم
- يمكن استخدام Firebase بدلاً من SQLite بتعديل `game.js`
